# 急救小本本 3.2

犬、貓、兔的休克與心肺復甦劑量計算機．依 RECOVER 2024 臨床指引與常用獸醫劑量整理。介面支援中文／English／日本語切換（右上角）。

兔的劑量主要外推自異寵文獻與臨床經驗（RECOVER 2024 僅涵蓋犬貓），切換到兔時介面會顯示提醒。輸入體重（與物種）後，各分頁會即時算出個別劑量；電解質分頁另會把每一步算式代入實際數值展開，可直接抄錄於病歷。

## 功能

| 分頁 | 內容 |
| --- | --- |
| 急救藥物 | Epinephrine、Atropine、Vasopressin、抗心律不整、酸鹼與電解質支持、反轉藥物、過敏性休克（Epinephrine IM、抗組織胺、類固醇） |
| 癲癇處置 | 正在抽搐的互動處置流程（9 種情境），16 種癲癇藥物依體重換算 mL |
| 升壓 / CRI | Dopamine、Dobutamine、Norepinephrine 等，含標準稀釋速率與注射幫浦速算法 |
| 輸液 / 電擊 | 休克輸液、高張溶液、膠體、血品、頭部外傷高滲治療（mannitol／高張食鹽水）與 MGCS 昏迷指數、體外／開胸電擊能量（超過機型上限會提示） |
| 電解質 / 輸血 | 拍照辨識檢驗值、輸血後預測 PCV、FFP 劑量與白蛋白變化、補鈉／補鉀最高輸液速率、高血鉀緊急處置、磷酸鉀 CRI（每項附詳細算式） |
| 酸鹼 | 血氣判讀、代償評估、AG 與 delta ratio、Stewart／半定量拆解、NaHCO₃ 兩種劑量公式 |
| 心電圖 / 抗心律不整 | 互動式心電圖判讀流程（17 種診斷，含無脈性 VT），15 種抗心律不整藥物依體重換算 mL |
| CPR 流程 | CPR 計時與給藥紀錄（見下）、BLS / ALS 週期、心律分支、5H 5T、ROSC 後照護 |
| 檢查清單 | 到院初評估到溝通紀錄的可勾選清單 |

急救藥物與升壓藥的每個劑量都標示每公斤用量（mg/kg、U/kg、mEq/kg、mL/kg）以便依患者情況調整，卡片下方並以小字附上該藥物的監測重點。

## 電解質 / 輸血 計算式

**輸血後預測 PCV**

```
BV      = BW × 90（犬）／60（貓）  mL
需求量 V = BV × (PCV目標 − PCV現值) ÷ PCV血袋
預測 PCV（臨床式）  = PCV現值 + V × PCV血袋 ÷ BV
預測 PCV（質量平衡）= (BV×PCV現值 + V×PCV血袋) ÷ (BV + V)
```

兩式差別在於是否計入輸入體積造成的稀釋。臨床標準公式不計，與需求量公式互為反算，也對應「1 mL/kg pRBC 約提升 1% PCV」的經驗法則；質量平衡式為保守下限。實測值通常落在兩者之間。

**FFP 劑量與白蛋白變化**

```
V         = 10–20 mL/kg × BW           凝血因子補充，可 q8–12h 重複
白蛋白量   = V × FFP白蛋白(g/dL) ÷ 100   g
分佈空間   = 0.3 L/kg × BW              含血管外間隙，換算成 dL
ΔAlb      = 白蛋白量 ÷ 分佈空間          g/dL
```

反算達到目標白蛋白所需量：`缺乏量(g) = 10 × (目標 − 現值) × BW × 0.3`，除以 FFP 白蛋白濃度即為體積。此式會凸顯 FFP 是效率極差的白蛋白來源——標準 10–20 mL/kg 只能提升約 0.1–0.2 g/dL，要提升 0.5 g/dL 通常需要 60 mL/kg 以上而造成容量過載。真正要補白蛋白應使用濃縮製劑。

**補鈉最高輸液速率**（Adrogué–Madias）

```
TBW    = 0.6 × BW  L
ΔNa/L  = (Na輸液 + K輸液 − Na血清) ÷ (TBW + 1)      K輸液 = 輸液本身含鉀（LRS 4、Normosol 5）＋ 另加 KCl
最高速率 = 允許矯正速率 ÷ |ΔNa/L|      慢性 0.5、急性 1.0 mEq/L/hr
```

不論急慢性，24 小時累計不超過 12 mEq/L；落差更大時會提示需分幾天矯正。矯正低血鈉過快會造成滲透性脫髓鞘症，矯正高血鈉過快會造成腦水腫。

**補鉀最高輸液速率**

```
最高速率 = (0.5 mEq/kg/hr × BW) ÷ (袋內 KCl 濃度 ÷ 1000)
```

補充濃度依滑動量表：血鉀 3.5–5.5 → 20、3.0–3.5 → 30、2.5–3.0 → 40、2.0–2.5 → 60、< 2.0 → 80 mEq/L。KCl 絕不可 IV push，需稀釋於輸液袋並充分混勻。

**磷酸鉀 CRI**（原液 3 mmol P/mL，含 4.4 mEq K/mL）

```
P 速率     = 0.03–0.12 mmol/kg/hr × BW      連續輸注 6 小時（預設 0.12，用於嚴重低血磷；輕中度用 0.03）
原液 mL/hr = P 速率 ÷ 3
伴隨鉀負荷 = 原液 mL/hr × 4.4 ÷ BW  mEq/kg/hr   （須 ≤ 0.5）
```

載液只能用 0.9% NaCl，含鈣輸液（LRS、Normosol-R）會產生磷酸鈣沉澱。

**血氣判讀與 NaHCO₃ 給法**

```
① 依 base excess：0.3 × BW × (−BE)          補足全部鹼缺乏
② 依目標 HCO₃⁻ ：0.3 × BW × (目標 − 實測)    部分矯正
兩者皆取 1/3 作首劑，20–30 分鐘給完
```

依物種參考值判定原發性異常與代償是否適當，並用白蛋白校正後的 anion gap、delta ratio（ΔAG ÷ ΔHCO₃⁻）與半定量 BE 拆解（自由水／氯／白蛋白／磷／乳酸／未測定陰離子）分辨高 AG 型與高氯型。偵測到乳酸以外的有機酸時會列出病因追查清單。呼吸性酸中毒、高 AG 型與 pH ≥ 7.2 皆不建議補鹼並說明理由。

## CPR 計時與給藥紀錄

位於「CPR 流程」分頁最上方。按下開始後：

- 計時總時間與 2 分鐘 cycle；cycle 到時響三聲並震動，按「心律檢查／換手」開始下一個 cycle
- 顯示距上次 Epinephrine 的時間：未滿 3 分鐘、可給下一劑（3–5 分）、已超過 5 分鐘；滿 3 分鐘時響一聲
- 給藥按鈕直接帶出依體重算好的 mL（Epinephrine、Vasopressin、Atropine／兔用 Glycopyrrolate、Amiodarone、犬 Lidocaine、NaHCO₃），以及電擊建議焦耳數
- 可開啟 110 次/分的按壓節拍器；計時中螢幕保持常亮
- 切到其他分頁時，頂部會出現 CPR 狀態列，提示音照常
- 紀錄存在這台裝置，重新整理不會遺失；可復原上一筆、複製或下載 .txt 貼進病歷，按「清除」才會刪除

## 拍照辨識檢驗值

在「電解質 / 輸血」與「酸鹼」兩個分頁皆可拍攝血氣或生化報告單，自動讀出 pH、PaCO₂、HCO₃⁻、BE、Na、K、Cl、乳酸、白蛋白、血磷、PCV 並填入各張計算卡。

**可加入多份報告**：判讀酸鹼需要的數值常分散在不同檢驗上（血氣有 pH 與電解質，白蛋白與磷通常只在生化），因此可連續加入多張，項目會自動合併。若同一項目在不同報告讀到不同數值，會標紅並列出各自的來源與數值，且**預設不勾選** —— 那可能是兩次採血時間不同，也可能是其中一次辨識錯誤，需要人判斷。

辨識使用 Tesseract.js 在瀏覽器端執行，**照片不會上傳到任何伺服器**；引擎於首次使用時從 CDN 取得約 4 MB。

辨識結果一律先進入審核表，逐項核對並勾選後才寫入計算欄位——超出合理生理範圍的值會標示並預設不勾選。

**審核表上的數值可直接修改**：辨識錯誤時當場改掉即可，不必套用後再去卡片上修。改過的欄位會標示原始辨識值供對照，範圍檢查會依新值重算，並自動勾選。

熱感應紙、反光與皺摺都會降低準確度，小數點位置尤其容易讀錯，套用前務必與報告單核對。

## 執行

主程式是單一 HTML 檔，另有 `vendor/`（React）與 `sw.js`（離線快取），無建置流程。本機直接用瀏覽器開啟 `index.html` 即可；要測試離線功能請起一個靜態伺服器：

```bash
npx serve .
```

## 離線使用

第一次連網開啟後，service worker 會把頁面、React（放在 `vendor/`）、Tailwind 與字型存在裝置上，之後診間斷網也能開啟與計算。建議在手機上「加入主畫面」當成 App 使用。拍照辨識的引擎與語言檔在第一次使用時下載並快取，之後同樣可離線使用。

`index.html` 採網路優先：有網路時一律拿最新版，因此平常更新不需要改 `sw.js`；只有更動 `vendor/` 或圖示時，才需把 `sw.js` 裡的 `VERSION` 加一。直接以 `file://` 開檔時不支援 service worker，此時仍需網路載入 Tailwind 與字型。

## 開啟次數統計

頁首的「累計開啟 N 次」使用免費的 [Abacus](https://abacus.jasoncameron.dev) 計數 API，只送出一個 +1，不含任何病患資料或識別資訊：

- 同一個分頁只計一次，重新整理不重複累加
- 離線時的開啟先記在裝置上，下次連網時補送（最多 20 次）
- 離線時顯示上次取得的數字

若想看每日趨勢、來源國家、裝置等細節，可另外申請 [GoatCounter](https://www.goatcounter.com)（免費、不使用 cookie），申請後把網站代碼加進頁面即可。

## 免責聲明

本工具僅供臨床參考。劑量為一般參考範圍，實際使用須結合患者狀況、藥廠濃度與臨床判斷。輸入的病患數值不會上傳，重新開啟即清空；CPR 計時紀錄只存在使用者自己的裝置。
